# 基础规范

跨语言、跨框架的基本开发原则与最佳实践。

- **极简原则**：代码简单明了，避免过度设计与抽象堆砌；优先使用原生内置功能。
- **延迟抽象**：避免提早封装，仅在逻辑第二次复用时提取。
- **默认中文**：界面设计默认使用汉字硬编码，除非明确要求处理多语言。多语言使用 `L()` 或 `LM('ModuleName', 'Key')`。
- **规范命名**：`name` 作英文唯一标识，`title` 作中文显示标题。
- **强制验证**：修改后必须通过 build 或基本代码语法检测（如 `php -l`）。
- **禁止冗余**：不写无用单行注释；不生成多余的 Markdown 文件（如框架说明、变更记录等）。
